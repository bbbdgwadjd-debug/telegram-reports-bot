# Telegram Reports Bot 🤖

بوت تيليجرام متقدم لإدارة الإبلاغات مع نظام حسابات متقدم

## المميزات ✨

✅ **إضافة حسابات**
- التحقق برقم الهاتف
- التحقق من كود تسجيل الدخول
- دعم التحقق بخطوتين (2FA)

📝 **نظام الإبلاغات**
- اختيار الكليشة (التصنيف)
- إدخال الموضوع
- إضافة روابط المنشور والقناة
- تحديد المخالفات
- تسجيل عدد التأخيرات بين الإبلاغات
- تسجيل عدد الإبلاغات الإجمالي

👨‍💻 **معلومات المطور**
- رابط المطور المباشر
- رابط قناة التحديثات

## التثبيت 🔧

### المتطلبات:
- Python 3.8+
- pip

### خطوات التثبيت:

1. استنساخ المستودع:
```bash
git clone https://github.com/bbbdgwadjd-debug/telegram-reports-bot.git
cd telegram-reports-bot
```

2. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

3. إعداد متغيرات البيئة:
```bash
cp .env.example .env
```

4. تعديل ملف `.env` وأضف:
- `BOT_TOKEN`: توكن البوت من @BotFather
- `DATABASE_URL`: رابط قاعدة البيانات (SQLite افتراضياً)
- `DEVELOPER_ID`: معرف المطور في تيليجرام
- `DEVELOPER_USERNAME`: اسم المستخدم (@isszo)
- `DEVELOPER_CHANNEL`: رابط قناة المطور

## التشغيل 🚀

```bash
python main.py
```

## قاعدة البيانات 🗄️

### جداول:

**Users** - بيانات المستخدمين
- telegram_id
- phone_number
- is_verified
- two_fa_enabled
- created_at

**Reports** - الإبلاغات المرسلة
- user_id
- category (الكليشة)
- topic (الموضوع)
- post_link (رابط المنشور)
- channel_link (رابط القناة)
- violations (المخالفات)
- delay_count (عدد التأخيرات)
- total_reports (عدد الإبلاغات)
- status
- created_at

**UserSessions** - جلسات المستخدمين
- user_id
- telegram_id
- stage (المرحلة الحالية)
- data (بيانات الجلسة)

## طريقة الاستخدام 📖

### إضافة حساب:
1. اضغط على زر "➕ إضافة حساب"
2. أرسل رقم هاتفك برمز الدولة (مثال: +966501234567)
3. أرسل الكود الذي ستتلقاه
4. حدد إذا كان حسابك عليه تحقق بخطوتين

### بدء إبلاغ:
1. اضغط على زر "📝 بدء الإبلاغ"
2. ملأ الحقول المطلوبة:
   - الكليشة
   - الموضوع
   - الروابط
   - المخالفات
   - عدد التأخيرات
   - عدد الإبلاغات
3. اضغط "✅ إرسال الإبلاغ"
